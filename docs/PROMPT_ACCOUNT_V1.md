# 小趴菜账号体系重构 ・ 标准提示词 V1.0

任务 ID：[TASK-ACCOUNT-V1]
范围：Web + Android（本期）；Windows / iOS / TV 仅预留接口文档，不改实现。

## 一、任务目标

将小趴菜从“本地双角色 + 多账号测试体系”重构为：
**单邮箱账号 + 云端统一认证 + 儿童设备强制归属账号 + 离线不降级** 的统一账号体系，
并完成全量自测与上线准备（上线清库由 Codex 在生产环境执行）。

## 二、不可违背的原则（产品负责人定稿）

1. 一个用户只有一个账号（一个邮箱），全平台统一；设备、策略、公告、报告均归属账号并随账号同步。
2. 取消任何“本地直接输入密码即可登录/进入家长端/儿童端系统级菜单”的用法。
3. 儿童端必须绑定某个家长在线账号后才能被管理，归属唯一。
4. 注册只支持邮箱：邮箱验证码注册、验证码登录辅助、验证码找回密码；不支持手机号。
5. 账号离线不影响已下发策略与公告的执行；离线仅停止同步，恢复后增量同步 + 补报。
6. 取消一切与上述体系冲突的功能与设定。
7. admin 系统管理账号同样绑定固定邮箱（如 admin@xiaopacai.com），挂 admin 角色，与用户账号隔离。
8. 进入家长模式（含从儿童端切回、App 退出后再进入）必须每次输入账号密码（云端账号密码，
   本机不存密码哈希；账号标识可记住，密码必须每次输入）。
9. 儿童端任何系统级菜单（设置、权限引导、无障碍/使用统计开关、卸载保护、设备管理器、
   退出守护等）必须输入账号密码。
10. 单账号设备数不设上限；超过 10 台给出预警提示。
11. 解绑/换绑必须家长账号密码验证；儿童端不提供解绑入口（服务端也不提供无凭证解绑）。

## 三、功能需求

### A. 服务端（xiaopacai-web/server）

A1 账号模型
- users 表以邮箱为唯一账号（Username 即邮箱，唯一索引）。
- admin 改为固定邮箱账号（角色 admin），与用户账号隔离；废弃 username=admin 的独立账号形态。

A2 注册（仅邮箱）
- POST /api/auth/register：邮箱 + 验证码 + 密码。
- 验证码由阿里云邮件推送发送；5 分钟有效、单码单用。
- 邮箱唯一校验；注册/发码按 IP + 邮箱双维度限速，防爆破。

A3 登录
- 邮箱 + 密码为主认证；邮箱验证码登录为辅助（可选实现，优先级低于密码）。
- 返回 JWT；登录失败限速沿用现有机制；成功/失败均审计。

A4 找回密码
- 忘记密码 → 邮箱验证码 → 重置新密码 → 重新登录。
- 废弃本地恢复码与本地密码找回路径。

A5 设备绑定 / 解绑 / 换绑
- 儿童端绑定：仅已登录家长账号可生成二维码/配对码（含证书指纹）；儿童端扫码后设备唯一归属该账号。
- device.OwnerUserId 强制非空；孤儿/无主设备逻辑改为启动时清理或迁移。
- 解绑/换绑：必须账号密码验证（新增一次性密码验证接口，或复用登录验证）；解绑即释放归属
  （沿用 D1：清空 OwnerUserId + PairCode），任意账号凭新码可重绑。
- 儿童端不提供解绑；服务端拒绝无凭证解绑请求。

A6 多设备
- 单账号不限设备数；设备列表/仪表盘超过 10 台显示预警。

A7 邮件服务（阿里云邮件推送）
- 接入 DirectMail（API 或 SMTP 二选一，建议 API + RAM AccessKey）。
- 全部配置走环境变量（AccessKey/Secret 或 SMTP 账号密码），禁止入库/入仓。
- 发信域名由用户完成开通与 DNS 验证；未配置邮件服务时注册/找回接口返回明确错误，不影响登录。

A8 安全与审计
- 验证码/注册/登录/找回/解绑全程限速；审计留痕（不含验证码、密码、令牌明文）。
- 密码哈希沿用 Argon2；JWT 密钥走环境变量。

### B. Web 前端（xiaopacai-web/web）

- 登录/注册/找回页面改为邮箱 + 验证码流程；删除手机号与本地恢复码入口。
- admin 后台登录改为邮箱账号。
- 设备绑定/解绑交互适配：解绑需账号密码二次确认。
- 单账号多设备（>10）预警提示。

### C. Android（xiaopacai/android）

- 移除本地家长密码体系：ParentPasswordManager 本地密码、恢复码、本地登录页全部退役。
- 家长模式：进入/切回/重启后必须账号密码登录；JWT 仅用于云端同步，不能免密进入家长模式。
- 儿童端系统级菜单（设置、权限引导、无障碍/使用统计开关、卸载保护、设备管理器、
  退出守护等）全部增加账号密码门禁。
- 儿童端绑定：只能绑定家长在线账号；界面展示绑定账号；无解绑入口。
- 离线：策略/公告/分类/限额本地缓存照常执行；恢复后增量同步 + 使用数据补报。
- 「清除账号绑定与本地数据」：改为账号密码验证后清除（保留现有清除语义与审计）。
- Windows / iOS / TV：本期不实现，仅输出接口预留说明。

## 四、必须取消/替换的现状

- Android 本地家长密码、恢复码、本地登录页。
- 儿童端“扫描家长端”本地 P2P 绑定作为账号载体（传输通道可保留，账号归属以云端为准）。
- 多账号测试体系（parent / admin / xwag14@126.com）与设备多归属/无主。
- Web 非邮箱账号、手机号注册路径。
- Windows 本地直连家长端（本期不动，预留账号接口）。

## 五、验收标准

1. 邮箱注册 → 验证码 → 登录 → 找回全链路可用（阿里云邮件推送实测送达）。
2. 家长端每次进入必须账号密码；错误密码拒绝且限速。
3. 儿童端所有系统级菜单均需账号密码。
4. 儿童端只能绑定一个家长账号；换绑/解绑需账号密码；解绑后可重绑。
5. 单账号多设备（≥2 台模拟器）策略/公告同步一致；>10 台预警生效。
6. 离线：断网后策略/公告照常执行；恢复后增量同步 + 补报。
7. admin 邮箱账号登录后台可用，与用户账号隔离。
8. 全量回归：Web 单测、Android 单测（120+）、Windows 单测（15）、npm build、Release APK 构建。
9. 安全：验证码爆破限速、审计留痕、无明文密钥入库入仓。
