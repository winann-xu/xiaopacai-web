=== 一、ADR 0009 已落库 ===
docs/adr/0009-account-v1-unified-email-account-system.md，11 条原则逐一落地映射（A1-A8/B/C），
核心决策如下（与标准提示词 V1.0 + 126 信逐条对齐）：

A1 账号模型：users.Username 即邮箱（小写归一 + 唯一索引），Email 列保留恒等兼容；
admin 邮箱化（Role=admin，如 admin@xiaopacai.com）；种子账号 admin123/parent123 删除，
启动时无 admin 且配置了 ADMIN_EMAIL/ADMIN_INITIAL_PASSWORD 则创建（MustChangePassword=true）。
上线清库由你执行（生产明文 SQLite 测试数据我侧不处理）。

A2 注册：POST /api/auth/email-code {email,purpose}（purpose ∈ register|login|reset_password；
6 位码 5 分钟有效、单码单用、重发作废旧码）+ POST /api/auth/register {email,code,password}。
限速：发码 IP 10/小时 + email 5/小时；验证 email 10/小时。邮件未配置 → 发码 503 明确报错。

A3 登录：/api/auth/login 仅接受邮箱；新增 /api/auth/login/code 验证码登录（辅助）。
失败限速沿用 5/小时 user+IP；虚拟哈希防枚举沿用。login-ticket（Web 扫码登录）保留
（依赖已登录设备确认，不违反原则 2）。

A4 找回：POST /api/auth/password-reset {email,code,newPassword}；成功后吊销该账号全部
RefreshToken。reset-ticket（线上恢复码）全链路退役删除。

A5 绑定/解绑/换绑：绑定侧现状已满足（二维码仅登录可生成、扫码后唯一归属）；
新增 /api/auth/verify-password {password} → 5 分钟一次性 action token；
Unpair 必须携带 Header X-Action-Token（无/过期 401），token 绑定 userId 防跨账号；
解绑即释放归属（沿用 D1）。儿童端无解绑接口。

A6 多设备：服务端不设上限；List 响应带 deviceCount；前端 >10 预警。

A7 邮件服务 + 126 管理页：IMailSender + DirectMailApiSender / SmtpSender 双实现；
配置优先级「数据库 mail_config（admin 页）优先 → 环境变量 MAIL_* 兜底 → 皆无则明确报错不阻断登录」；
Secret（AccessKeySecret/SmtpPassword）用环境变量 XIAOPACAI_MASTER_KEY（32B hex）AES-256-GCM
加密入库，禁止明文；主密钥未配置时拒绝保存 Secret 并提示。
接口（仅 admin）：GET/PUT /api/admin/mail-config（Secret 脱敏回显「已设置」，留空=不变）、
POST /api/admin/mail-config/test {to}；限速+审计（不含 Secret 明文）；保存即热生效。

A8 安全：验证码/注册/登录/找回/解绑/邮件配置全程限速+审计；验证码/密码/令牌/Secret 不入审计日志响应；
Argon2 沿用；JWT 密钥走环境变量。

B Web 前端：登录页邮箱+密码主流程 + 验证码登录 tab + 注册/找回两步流程（删手机号/恢复码入口）；
解绑弹窗内密码二次验证；>10 台预警条；admin「系统设置→邮件设置」页（通道表单/脱敏回显/测试发送/
状态与最近结果/阿里云开通说明文案）。

C Android：退役 ParentPasswordManager 本地密码+恢复码+本地登录页；家长模式每次进入/切回/重启
必须邮箱+密码云端验证（JWT 仅同步用，密码不落盘，只记住邮箱标识）；儿童端全部系统级菜单
统一 SystemGateDialog 每次密码验证；绑定账号展示、无解绑入口；离线语义=缓存照常执行+恢复增量
同步补报（现状已满足，文档化）；清除账号改为云端密码验证（离线拒绝清除，安全优先）。
