#### SQLCipher 初始化服务
- 首次运行：生成 32 字节随机密钥 → Base64 编码 → 存储到 Data/.dbkey
- 后续运行：从 .dbkey 加载密钥
- 支持环境变量 Database:Password 覆盖（生产推荐）
- EF Core 连接拦截器（SqlCipherInterceptor）：每次连接自动执行 PRAGMA key
- 文件权限：Linux/macOS chmod 600

#### 密码哈希服务
- 默认：Argon2id（64MB 内存 / 4 次迭代 / 2 并行度 / 32 字节盐值）
- 兼容：PBKDF2 SHA-256 600,000 次迭代 / 32 字节输出
- 自动检测：盐值前缀 $argon2id$ → Argon2；否则 → PBKDF2
- Fixed-time comparison（防时序攻击）

### P2-B: 认证与鉴权

#### AuthController API（server/Controllers/AuthController.cs）
| 端点 | 鉴权 | 说明 |
|------|------|------|
| POST /api/auth/login | 无 | 用户名+密码 → Access+Refresh Token |
| POST /api/auth/logout | Bearer | 吊销当前 Refresh Token |
| POST /api/auth/refresh | 无 | 用 Refresh Token 换取新 Token 对 |
| POST /api/auth/change-password | Bearer | 旧密码验证 → 新密码哈希 → 吊销所有 Token |
| GET /api/auth/me | Bearer | 获取当前用户信息 |

#### JWT 配置
- Access Token：60 分钟过期 / HMAC-SHA256 签名
- Refresh Token：7 天过期 / 随机 64 字节 opaque token / SHA256 哈希存储
- Refresh 轮转：旧 Refresh 吊销 + 新 Refresh 签发（防重放）
- 改密安全：改密后立即吊销用户所有 Refresh Token

#### 角色策略
- AdminOnly：仅 admin 角色
- ParentOrAdmin：admin 或 parent 角色
- 用法：[Authorize(Roles="admin")] 或 [Authorize(Policy="AdminOnly")]

#### Swagger
- JWT Bearer 安全方案已配置
- 在 Swagger UI 右上角 Authorize 按钮输入 "Bearer {token}" 即可测试受保护 API

#### 种子数据
- 默认管理员：admin / admin123（Argon2id 哈希，首次启动自动创建）
