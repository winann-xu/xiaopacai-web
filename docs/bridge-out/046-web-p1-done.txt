### 4. 数据库 Schema（server/Data/Schema.sql）
8 张表（对照 2.0 AppDatabase + 新增管理表）：

| 表名           | 说明               | 关键字段/特性 |
|----------------|-------------------|---------------|
| users          | 用户账号           | role(admin/parent), PBKDF2/Argon2 hash |
| devices        | 儿童设备           | pair_status, online_status, cert_fingerprint |
| policies       | 策略配置           | 每日限额/就寝/分类/黑白名单/超时处理 |
| announcements  | 公告管理           | 优先级/状态/有效期/定向推送 |
| usage_records  | 使用记录(原始)     | 分类/时长/拦截标记 + 索引 |
| daily_summary  | 每日汇总(聚合)     | 分类分钟统计 + UNIQUE(device,date) |
| audit_logs     | 审计日志 🆕        | action/target/detail + 索引 |
| pairing_info   | 配对信息 🆕        | 发现方式/证书指纹/过期时间 |

所有表：CHECK 约束 + 外键(CASCADE/SET NULL) + 优化索引
种子数据：admin 账号占位符
